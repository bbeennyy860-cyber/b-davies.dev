Overview

Why this exists

99.37% of tokens launched on Pump.fun fail to graduate. Speed sniping — the dominant retail strategy — competes against bots with sub-millisecond execution, MEV searchers, and jito bundlers. It is a race you cannot win with a Python script and a residential IP.

The signal that actually predicts graduation is not speed. It is who is buying, and whether they are coordinating. A small cohort of wallets — identifiable by their consistent early presence on tokens that later 10x — leave a detectable on-chain fingerprint before the retail crowd arrives. Vex is built to read that fingerprint.

The premise: track the 57 wallets with the strongest historical accuracy. When multiple of them buy the same new token within a short window, treat that as a coordinated signal. Score it through a multi-factor model. Size positions by conviction tier.

Signal Engine

Multi-factor scoring model

Each signal is scored on a 0–1 scale. The final score is a weighted linear combination of five factors. The dominant weight on smart_money reflects the core thesis: nothing else matters if the alpha wallets are not present.

def score_signal(token: TokenData, alpha_hits: int) -> float:
    sm_score   = min(alpha_hits / 3, 1.0)    # saturates at 3+ wallets
    mom_score  = _momentum_score(token.volume_5m, token.price_delta_5m)
    safe_score = _safety_score(token.rugcheck_score, token.lp_locked)
    liq_score  = _liquidity_score(token.liquidity_usd)
    soc_score  = _social_score(token.twitter_mentions)

    return (
        0.45 * sm_score  +
        0.25 * mom_score +
        0.15 * safe_score +
        0.10 * liq_score  +
        0.05 * soc_score
    )

Conviction tiers map score ranges to position sizes. Tier 1 requires a score above 0.85 with 3+ alpha wallets buying within 90 seconds of each other. The threshold was derived from backtest results — below 0.85, the edge collapses.

Technical Decisions

Design rationale

  • Linear scoring over multiplicative A multiplicative model zeroes out any signal with a zero factor — one bad safety score kills the trade regardless of strong smart money presence. Linear composition allows partial conviction. A token with strong smart money flow and weak social signal still scores reasonably. The model is calibrated to what actually matters, not what looks elegant on paper.
  • Alpha wallet tracking over speed sniping Speed sniping is a solved problem for well-capitalised actors. The marginal cost of a jito bundle is negligible for an entity doing $1M/day volume. Competing on latency from a Python process is a structural disadvantage. Alpha wallet detection shifts the competition axis from latency to pattern recognition — a domain where a well-curated dataset creates durable edge.
  • Base58 case sensitivity Solana addresses are base58-encoded and case-sensitive. Normalising to lowercase breaks address matching silently — no error thrown, just a wallet that never appears in the database. Every address in the alpha wallet DB is stored and compared in its original base58 form. This burned significant time early on. It is now enforced at the ingestion layer with a validation step before any write.
  • Helius Enhanced Transactions over raw RPC Helius Enhanced API parses raw transaction data into structured swap events, removing the need to manually decode instruction data and program logs. The alternative — parsing Pump.fun and Raydium instruction layouts from raw bytes — is brittle against program upgrades. Enhanced transactions provide a stable schema at the cost of API rate limits, managed via async batching with exponential backoff.
Results

Backtest outcomes

Backtested against 8,000+ historical signals pulled from on-chain data. The evaluation period covers the high-volatility meme season of late 2024 through early 2025. Metrics reflect paper-trading outcomes without slippage modelling, so live performance will be softer.

The 30.8% win rate on scores above 0.85 is the number that matters. Given a 3-to-1 target (T1 entries target 3x before circuit break), positive expected value holds above roughly 25% win rate. The 8.3% ROC across all signals is the aggregate including low-conviction T3 entries which drag the overall figure.

Key finding: coordinated wallet count is the strongest single predictor. Signals with 4+ alpha wallets buying within 60 seconds had a 41.2% win rate, versus 18.7% for single-wallet detections. This validates the weight distribution in the scoring model.
